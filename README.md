# Mente

Juegos para entrenar la mente: Sudoku, Memotest, 2048, Buscaminas, Nonograma, Cálculo mental y Palabra del día.

Funciona sin internet. Para instalarla en el iPhone: abrir la página en Safari → Compartir → Agregar a pantalla de inicio.

Cada vez que se hace un cambio hay que subir el número en `version.json` y en `APP_VERSION` (js/app.js) para que el botón "Actualizar" lo descargue.
